# MBTI64 品牌视觉识别规范（Brand Guidelines）

> 版本 1.0 · 适用于 MBTI64 网站、分享海报、社交图与后续新增页面。
> 本文件是项目的长期 CI 基准：新增页面、组件或人格卡片时，先对照第 9 节检查清单。

---

## 1. 品牌定位与标语

| 项目 | 内容 |
|---|---|
| 品牌名 | **MBTI64**（英文并列名：64 Personalities） |
| 中文描述 | 64 型人格 · 自我认知探索平台 |
| 英文描述 | 64 Personalities · Discover Yourself |
| 主标语 | **64 PERSONALITIES · ONE UNIQUE YOU** |
| 辅助标语 | DISCOVER YOURSELF. UNDERSTAND DIFFERENCES. |
| 首页主标题 | 你的性格，在 64 型里有多稀有？ |
| 品牌定位 | 现代化、多维度、专业、友好的人格探索平台 |
| 语气 | 理性、克制、正向；解释差异，不做人格优劣判断 |

品牌叙事三段式：

1. **四种颜色代表人格的多样性** —— 四大人格族群色。
2. **深海军蓝代表品牌的专业性** —— 字标、标题与核心交互。
3. **几何 Logo 代表 64 种人格背后的整体性** —— 四象限图形聚合为一个符号。

免责声明口径：本项目为原创独立产品，与 16Personalities 无任何关联，不使用其商标或受保护图形；测评结果仅供娱乐与自我探索，不构成心理咨询或诊断。

## 2. Logo 规范

### 2.1 结构

- **标记（Mark）**：四象限几何图形，四块圆角模块围绕中心聚合，构成一个整体符号。
- **字标（Wordmark）**：`MBTI64`，无衬线 ExtraBold，深海军蓝 `#0F2747`。
- **固定比例**：主标画布 `924 × 240`；堆叠版 `240 × 317`；图标 `240 × 240`。
- **色彩秩序**：左上=分析家紫、右上=外交家绿、左下=守护者蓝、右下=冒险家黄（与族群语义绑定，不可换位、不可改色）。

### 2.2 变体与使用场景

| 文件 | 画布 | 形态 | 使用场景 |
|---|---|---|---|
| `logo-primary.svg` | 924×240 | 图形 + 深蓝字标 | 默认横向组合；页头、文档页眉、海报顶部 |
| `logo-light.svg` | 924×240 | 图形 + **白字标** | 深色/深蓝底反白场景 |
| `logo-dark.svg` | 924×240 | 全深海军蓝单色 | 单色印刷、传真、浅底极简场景 |
| `logo-mono-black.svg` | 924×240 | 纯黑单色 | 黑白印刷、合作伙伴物料 |
| `logo-mono-white.svg` | 924×240 | 纯白单色 | 深色照片/深底反白 |
| `logo-stacked.svg` | 240×317 | 图形上 + 字标下 | 正方形/竖版容器、海报底部、开屏 |
| `logo-stacked-{light,dark,mono-black,mono-white}.svg` | 240×317 | 对应色调竖版 | 同上，按背景选择色调 |
| `logo-icon.svg` | 240×240 | 仅四色图形 | 无字标场景；站点大图标、装饰 |

| `apple-touch-icon.png` | 180 | 浅底四色图形 | iOS 主屏图标 |
| `icon-192.png` / `icon-512.png` | 192/512 | 浅底四色图形 | PWA / Android |
| `icon-512-maskable.png` | 512 | 浅底安全区图形 | Android maskable |

站内统一由 `components/BrandLogo.tsx` 引用上述矢量源文件（`variant` × `tone`），禁止在组件里另画一套 Logo。

### 2.3 最小尺寸与安全边距

- 图标最小 **24×24 px**；主标高度最小 **24 px**；堆叠版宽度最小 **120 px**。
- 安全边距 = 标记边长的 **25%**，四周不得出现文字、边框、其他图形。
- 16 px 以下只用 favicon PNG，不使用主标。

### 2.4 禁止项

- 禁止拉伸、压扁、旋转、倾斜、描边、加投影、加发光。
- 禁止改四色顺序、改色值、用渐变替代纯色块。
- 禁止把 Logo 放进胶囊/圆角卡片里再套边框。
- 禁止在深色底使用深蓝字标版本；禁止在浅色底使用白字标版本。
- 禁止用截图/位图放大代替矢量；禁止把 Logo 作为页面大背景纹理。
- 禁止声称与 16Personalities 有关联，禁止使用第三方品牌图形。

## 3. 色彩系统

### 3.1 品牌基础色

| Token | 色值 | 用途 |
|---|---|---|
| `--brand-navy` / `navy` | `#0F2747` | 字标、主标题、核心按钮、页脚品牌区 |
| `navy-deep` | `#0A1B33` | 主按钮 hover |
| `navy-soft` | `#E8EEF5` | 选中态浅底、信息块 |
| `--brand-background` / `surface.page` | `#F8FAFC` | 页面底色 |
| `surface.card` / `paper` | `#FFFFFF` | 卡片、内容面 |
| `surface.hover` | `#F1F5F9` | 悬停底色 |
| `--brand-border` / `border` / `line` | `#E7ECF2` | 默认边框、分隔线 |
| `border.strong` | `#CBD5E1` | 次级按钮边、强调分隔 |

原则：页面保持浅色底，**不做大面积深色主题**；深海军蓝只用于文字、按钮与少量整块 CTA。

### 3.2 四大人格族群色

| 族群 | `color`（图形/色点） | `text`（白底文字，≥4.5:1） | `soft`（标签底） | `light`（区块淡底） |
|---|---|---|---|---|
| 分析师 Analyst | `#7B61FF` | `#5A3FD1` | `#E5DEFF` | `#F1EDFF` |
| 外交家 Diplomat | `#4CAF6B` | `#24803F` | `#D5EFDE` | `#EAF7EE` |
| 守护者 Guardian | `#4A90E2` | `#1E6FB8` | `#D6E8FB` | `#EAF3FD` |
| 冒险家 Adventurer | `#F6C343` | `#8A6200` | `#FBE9B3` | `#FFF7DF` |

使用规则：

- `color` 只用于图形、色点、4px 色条、图表填充与 Logo，**不直接作为正文/小字颜色**。
- 白底文字一律用 `text` 变体（已加深，满足 AA 对比度）。
- `soft` 用于族群 chip / 小标签；`light` 用于大区块淡底。
- 四色只用于**分类识别**，不平均铺满页面，不做彩虹渐变。
- 稀有度、状态、按钮**不得**借用族群色。

### 3.3 中性文字色与语义状态色

| Token | 色值 | 用途 |
|---|---|---|
| `text.primary` / `ink` | `#172B45` | 正文、卡片标题 |
| `text.secondary` / `ink-soft` | `#64748B` | 辅助说明、次级信息 |
| `text.muted` / `ink-mute` | `#94A3B8` | 极弱提示、占位 |
| `success` | `#24803F` | 成功/已完成 |
| `warning` | `#8A6200` | 警示 |
| `error` | `#B42318` | 错误、危险操作 |
| `info` | `#1E6FB8` | 信息提示 |
| `disabled` | `#94A3B8` | 禁用态 |

语义色与族群色在色相上刻意区分（体验上的绿/黄与外交家绿/冒险家黄不得互相替代）。

### 3.4 稀有度色阶（中性）

7 档稀有度统一使用海军蓝→石板灰的中性梯度，仅用于档位标签与金字塔，不参与品牌四色：

`#0F2747` → `#1E3A5F` → `#33507A` → `#4A678F` → `#64748B` → `#8291A5` → `#94A3B8`（浅底对应 `#E8EEF5`…`#F7F9FB`）。

## 4. 字体与排版

字体栈（无外部字体请求，离线可用）：

```css
font-family: Inter, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif;
```

| 层级 | 桌面 | 移动 | 字重 | 颜色 |
|---|---|---|---|---|
| 页面 H1 | 40–44 px | 32–34 px | 800 | navy |
| 页面 H2 | 28–32 px | 24–26 px | 700 | navy |
| 区块标题 | 22–26 px | 20–22 px | 700 | navy |
| 卡片标题 | 16–20 px | 16–18 px | 600 | ink |
| 正文 | 15–16 px / 1.75 | 14–15 px | 400 | ink / ink-soft |
| 辅助信息 | 12–13 px | 12–13 px | 400–500 | ink-mute |
| 数据指标 | 28–40 px | 26–32 px | 800 | navy |
| 大写英文标签 | 11.5–12 px `tracking-[0.16em]` | 同 | 700 | ink-mute |

规则：

- 数字使用 `font-variant-numeric: tabular-nums`（`.num-hero`），保证指标对齐。
- 英文全大写标签 = `.eyebrow`；中文标题不加字间距。
- 全站字重不超过 3 档（400 / 600 / 800）。
- 段落宽度 ≤ 34em（`.prose-type`），行高 1.75–1.85。

## 5. 形状、阴影、间距与动效

| Token | 值 | 说明 |
|---|---|---|
| `rounded-card` | 12 px | 卡片、输入框 |
| `rounded-panel` | 16 px | 大区块、Hero 面板、弹层 |
| `rounded-[10px]` | 10 px | 按钮 |
| `rounded-full` | — | 仅 chip / 徽标 / 色点 |
| `shadow-card` | `0 1px 2px rgba(15,39,71,.06)` | 默认卡片 |
| `shadow-lift` | `0 12px 28px -14px rgba(15,39,71,.18)` | hover / 浮层 |
| 间距基数 | 4 px | 常用 8/12/16/24/32/48/64 |
| 内容最大宽 | 1120 px | 桌面内容区 |

动效：

- 统一缓动 `cubic-bezier(0.22, 0.61, 0.36, 1)`。
- 只允许 `fade-in`（220ms）与 `radar-draw`（800ms）；hover 位移 ≤ 2px。
- 必须尊重 `prefers-reduced-motion: reduce`（已在 `globals.css` 全局关闭）。

## 6. 组件规范

### 6.1 按钮

| 类型 | 规格 | 使用 |
|---|---|---|
| Primary `.btn-primary` | navy 实心、白字、min-h 44px、10px 圆角 | 开始测评、主要提交 |
| Secondary `.btn-ghost` | 白底、`#CBD5E1` 边、navy 字 | 次要入口、60 题精简版 |
| Tertiary `.btn-tertiary` | 透明底、navy 字、hover `navy-soft` | 文字型操作 |

族群色按钮仅允许出现在「族群筛选/分类」上下文；测评、结果、导航一律 navy。

### 6.2 卡片

`.card` = 白底 + 1px `#E7ECF2` 边 + 12px 圆角 + 极轻阴影；hover 上浮 2px（`.card-hover`）。
禁止：多色背景卡、彩色边框卡、玻璃拟态、重投影。

### 6.3 标签（必须区分类型）

| 标签 | 样式 |
|---|---|
| 族群标签 | `soft` 底 + `text` 色 + 族群图标 + 中文名（信息不只靠颜色） |
| 人格代码 | `font-mono` + navy，中性底或白底 |
| 稀有度标签 | 中性色点 + `tier.text` + 品牌边框，不用族群色 |
| 测评状态标签 | 语义色（success/warning/info） |
| 数据提示 | `ink-mute` 小字，无底色 |

禁止所有标签都用胶囊渐变。

### 6.4 图标

- 线性图标统一 Phosphor（`@phosphor-icons/react`），线宽按尺寸默认，尺寸 16/20/24。
- **Emoji 不得作为核心品牌图标**（头像、族群、维度、按钮均不用）。
- 图标与文字间距 6–8 px；仅图标按钮必须有 `aria-label`。

## 8. 无障碍与响应式

- 文字对比度：正文 ≥ 4.5:1；大号标题 ≥ 3:1；族群 `color` 不用于小字。
- 不能只靠颜色区分族群/稀有度：必须同时有中文名、图标或文字标签。
- 触摸目标 ≥ 44×44 px；焦点环 navy 2.5px + 3px offset。
- 断点验证：1440 / 1280 / 1024 / 768 / 390 / 375 / 360，均不得出现横向溢出。
- 移动端标题缩小、卡片自动降列；图表容器自适应（SVG viewBox）。
- 所有图片有 `alt` 或 `aria-hidden`；装饰性图形不进无障碍树。

## 9. 新增页面 / 组件 CI 检查清单

- [ ] Logo 来自 `public/assets/brand`，没有另画/截图。
- [ ] 颜色只引用 Design Tokens，无硬编码十六进制（族群色读 `GROUP_META`）。
- [ ] 深海军蓝仍是主交互色；页面无大面积深底或彩虹渐变。
- [ ] 四色只出现在族群识别；稀有度/状态/按钮未借用族群色。
- [ ] 字体来自统一字体栈；数字使用 tabular-nums。
- [ ] 卡片圆角 12/16px、边框 `#E7ECF2`、阴影最多 `shadow-lift`。
- [ ] 标签按 6.3 分类，未全部做成渐变胶囊。
- [ ] 图标为 Phosphor 线性，无 emoji 核心图标。
- [ ] 移动端 360px 无横向溢出，触摸目标 ≥ 44px。
- [ ] 文案品牌名统一 `MBTI64`，含「与 16Personalities 无关联」免责口径。
- [ ] 新增资源同步更新 `site.webmanifest` / metadata / OG（如涉及）。
