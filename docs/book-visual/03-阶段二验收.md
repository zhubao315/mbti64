## 2. 角色一致性（INFJ 五张）

- 恒定项一致：深棕齐肩直发、暖米色几何切面、点状眼、森林绿高领长披风、薄荷青内衬、胸前棱镜扣、多面体提灯。
- 变化项符合规范：C-O 半侧身/探针 + 新芽、A-O 跨步/破壁箭头、A-H 站稳/六边形基座、C-H 内收/水晶罩。
- 缩略可辨识：五张缩至 160px 后仍可按"姿态 + 季节符号"区分。

## 3. 遗留与后续

1. T1 上留白约 7%，低于 18% 规范；正式 1200×1600 排版版需人工补边或重出。
2. V2 内部枝状分形偏"树枝/神经"，进入正式资产前应收敛为纯几何分形。
3. 全部参考图为 1024×1536 / 1536×1024，终稿需按用途表重采样到 1200×1600、2400×1350 或印刷 210×285mm + 3mm 出血。
4. 封面/封底/书脊仍为纯图版；带排版参考线版与文字分层版属于阶段五。
5. 正式资产目录 `public/assets/book-visual/` 尚未创建，等阶段四批次图通过 QC 后再建。
