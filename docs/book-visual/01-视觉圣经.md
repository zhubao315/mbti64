# 《千分之一的你》视觉圣经 · Solar-Poly 64

- 版本：v1.0（冻结候选）
- 适用范围：书籍封面系统、六卷扉页、16 基础原型图鉴、64 亚型卡牌、章节场景图、网站与分享图
- 一致性锚点：本文件一经冻结，所有生图提示词只引用，不各自改写

## 0. 全局铁律

1. 全书只使用一套视觉系统：**「日光棱镜 Solar-Poly 64」**——低多边形几何折面 + 彩色半透明磨砂亚克力 + 淡彩琉璃 + 细金属神经拓扑线 + 轻柔投影。
2. 背景默认 **纯白 `#FFFFFF` 或极浅暖白 `#FDFCF9`**，禁止黑底、暗色霓虹、赛博朋克。
3. 图内 **不生成长段文字**。书名、卷名、章节名、类型代码、作者与出版信息一律由后期排版叠加；如需极少短字符，位置必须固定且不承载信息。
4. 主体距画面边缘 **≥ 8%**；顶部与底部必须留出排版安全区，不贴边、不裁切头部/手部/信物。
5. 人物为 **中性青年化几何卡通角色**，极简点状眼睛，不做写实人脸、不做日系大眼、不做过度 Q 版。
6. 不出现：真人照片、写实场景、写实大脑、恐怖神经元、水印、随机 logo、随机英文标题、多余角色、无意义装饰。
7. 不把人格画成 **医学诊断或固定命运**；稀有度只表达分布与生态位，不表达等级优越。
8. 临时图、试做图、未通过 QC 的图 **不得进入 `public/assets/book-visual/` 正式资产目录**。

## 1. 全书视觉定位

### 1.1 关键词
- 结构：几何、折面、六维、拓扑、秩序
- 材质：磨砂亚克力、淡彩琉璃、纸张折叠、细金属线
- 气质：克制、温柔、理性、专业、收藏感
- 明度：高明度、干净留白、印刷友好

### 1.2 读者感受
翻开是"一本可以长期使用的心理工具书"，而不是"一个娱乐测试的周边"。读者应当感到被认真对待：图形精确但不冰冷，颜色丰富但不喧哗，人物可自我投射但不被定型。

### 1.3 视觉差异化
| 对照对象 | 常见做法 | 本书做法 |
|---|---|---|
| MBTI 娱乐测评插画 | 大头贴式人物、强表情、梗图化 | 7 头身几何折纸角色、克制表情、信物承载行为方式 |
| 严肃心理学工具书封面 | 抽象色块、冷灰、学术图表 | 有温度的四色棱镜核心 + 开放的成长循环 |
| 通用 3D 渲染插画 | 高光塑料感、暗底辉光 | 哑光折面 + 半透明磨砂 + 纯白底柔投影 |
| 人格"类型卡" | 一张脸换四种滤镜 | 同一角色只改姿态/手势/气场/季节符号，信物恒定 |

### 1.4 明确不做什么
不做"64 个不同的人"（=64 个偶像），只做"16 个角色 × 4 种生命状态 = 64 种可调用的工具"。封面不做 64 人群像。

### 2.1 跨族群共同项
- 肤色统一为暖米色几何切面（`#F2D6C2` 明部 / `#D9AE95` 暗部），不随族群变色。
- 头发统一自然黑或深棕（`#2B2320` / `#4A342A`），**禁用彩色发色**；族群色只出现在服装、信物、气场与背景符号上。
- 服装允许两色：族群主色 + 一族群辅助色；第三色只能作为 ≤10% 的点缀。
- 高光不使用纯白爆点，用 8% 不透明度的柔光面。

### 2.2 印刷修正（CMYK 侧）
屏幕四色偏荧光，上纸需降饱和并补黑：
- 丁香紫上纸略偏蓝紫，避免落入"品红紫"；深紫补 K 到 30 以上。
- 森林绿降黄，避免印成"草绿荧光"。
- 冰川蓝降青、提 M，避免印成"电光蓝"。
- 琥珀金加少量 M，避免纯黄在无光纸上发灰。
- 四色在灰度复印下仍需可区分——依赖形状差异（三角/圆/六边形/闪电）作为第二编码。

## 5. 角色一致性规范

1. **同基础型四态可辨认**：把 4 张缩到 160px 并排，仍能一眼判断"是同一个人在不同状态"。
2. **同族群 16 角色统一**：同一族群的色相偏差 ≤ 8°，材质与光线方向一致。
3. **缩略图可区分**：512px 与 160px 下，靠信物剪影 + 姿态 + 背景符号三件事区分，不靠细节。
4. **面部极简**：不做复杂五官；表情只通过眉眼点位与头部角度表达。
5. **信物必现**：任何一张图缺核心信物即判不通过。
6. **不性别化过度**：不通过胸部、腰臀曲线强调性别。
7. **不复制第三方角色**：16Personalities 只能作为"几何卡通 + 色块识别"的风格参考，人物造型、服饰、姿态、商标元素必须原创。

## 8. 色彩规范（RGB 网页版 + CMYK 印刷版）

> CMYK 为 Coated FOGRA39 近似值，最终以打样校准为准；不得以屏幕色直接交付印厂。

| Token | 用途 | RGB | HEX | CMYK 近似 |
