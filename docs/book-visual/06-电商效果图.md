# 《千分之一的你》电商 3D 效果图

> **状态**：2026-11-11 落盘。5 张可用主图（确定性渲染）+ 4 张氛围图（AI 生成）。
> **生成器**：`scripts/render_book_mockup.py`（确定性）/ `scripts/gen-book-mockup.mjs`（AI 氛围图）
> **输出目录**：`书-千分之一的你/装帧/`

---

## 1. 为什么主图不能用 AI 画

电商主图必须和实物一致。封面上的「千分之一的你」「从16型到64型：人格画像、差异理解与成长练习」「朱宝 著」一个字都不能错。

AI 会把它们画成乱码 —— 本项目实测：

- `minimax-h3-image` 在第六卷扉页上写出「心理学书设第六卷扁」；
- 同一模型做 3D 立体化时，**书脊上的竖排书名被改写成「封面你」「作者 音它」**，副标题词序也换过。

所以主图反过来做：**把书当成一个真实的盒子建模**，尺寸、旋转、透视、光影、纸页厚度、投影全部由脚本算准；封面本体是把真实的 `封面.png` 透视变换贴上去 —— 逐像素一致，不会有错字。

AI 的立体效果图只作**氛围图**（详情页中段、场景化版面），且逐张放大核对过文字才用。

## 3. 渲染是怎么算的

**书盒建模**（毫米）：

- 宽高比严格取自 `封面.png`（1200×1600 = 0.75），贴图不会被拉伸；`BOOK_W = 150`，`BOOK_H = 200`，`BOOK_D = 24`（装订厚度）。

**相机**：`yaw` 绕书自身竖轴（负值 = 右侧书口转向镜头，正值 = 左侧书脊转向镜头），`pitch` 在**世界坐标**里俯仰（先 yaw 后 pitch —— 反过来写的话翻到封底看时俯视会变成仰视），透视投影 `x = f·X/(Z+dist)`。

**可见面**：按法线在相机空间的 z 分量判定（> 0.02 可见），凸体各面投影互不重叠，按由远及近绘制。

**贴图**：
- 正面 = `封面.png`；封底 = `封底.png`（左右与正面镜像，因为背面视角里 +X 在观察者左侧）；书脊 = `书脊.png`。
- **书脊条是「印刷拼版」，不是书脊本身** —— 它按 46×291mm @300dpi 制作，直接贴到书脊面上会把字压扁。做法：把设计带（x 222–440、y 282–3325）整体等比缩放到「书脊面高 BOOK_H」，宽度按比例居中贴进 `BOOK_D` 宽的书脊面，其余补封面纸色。这样竖排书名的字形比例才对。
- 书口 = 米白纸色 + 细密页纹（页纹要弱，强了像条码）；顶面 = 书口切口（页纹横向）；底面 = 封面板切口（不是纸页）。

**透视变换**：PIL 的 `Image.QUAD` 语义不符合预期（源图整幅映射进整幅画布，框外全黑），所以自己解单应矩阵（DLT，8 个未知数最小二乘）做逆映射 + 双线性采样。

**光影与影子**：
- 每个面一个亮度系数 + 沿光照方向的线性渐变（光从左上）。
- 落影：把书的轮廓压扁（k = 0.22）贴到台面上、向右偏移 —— PIL 的 `AFFINE` 是「输出坐标 → 输入坐标」，压缩比要取倒数（`1/k`），锚点要写成 `-ground_y·(1-k)/k`。
- 接触影：紧贴书底的一条实影 —— 这一条决定书「站得住」还是「浮着」。

## 4. 氛围图（AI 生成，详情页用，非主图）

`scripts/gen-book-mockup.mjs` 走 `/images/edits`，把真实封面作为 `<Picture 1>` 喂给模型做立体化。产物在 `assets-hifi/book-mockup/`，挑过之后落到 `装帧/`：

| 文件 | 场景 | 文字核对 |
|---|---|---|
| `mood-flat-top.jpg` | 平铺俯拍 | 标题 / 英文行 / 副标题 / 作者 **全部正确** |
| `mood-hero-3q.jpg` | 3/4 俯视 | 同上，全部正确 |
| `mood-scene-desk.jpg` | 桌面场景（带笔作尺度参照） | 同上，全部正确 |

**AI 侧立图（`side-standing`）不上架** —— 它的书脊文字被改写成「封面你」「作者 音它」，书脊上的字是品牌，不能错。书脊视角改用确定性渲染的 `mockup-spine.jpg`。

**两条限制，用之前必须知道**：

1. 氛围图里的封面**不是印刷品的逐像素复制**，是模型按原封面重画的「近似版」（构图一致，棱镜个体形状有出入）。上架主图一律用确定性渲染，氛围图只放详情页做场景化版面。
2. 任何一张 AI 图的小字都必须**放大逐字核对**后才用 —— 同一批模型输出里，就有封面全对、书脊全错的。


## 5. 重新生成

```bash
# 主图（4 个视角）
python3 scripts/render_book_mockup.py

# 方形主图（电商 1:1）
python3 scripts/render_book_mockup.py --size 1536x1536 --only mockup-hero-3q --out 装帧

# 纯白底变体
python3 scripts/render_book_mockup.py --bg white --only mockup-hero-3q --out 装帧

# 氛围图（AI，单张约 60 秒；首次含模型加载更久）
node scripts/gen-book-mockup.mjs --angle hero-3q
```

视角参数（`target_h` 等）都按画面高度的比例写死，所以换分辨率（4:3 / 1:1）不用重调。

依赖：`numpy` + `Pillow`，不需要 OpenCV。渲染是幂等的 —— 同样的输入产出同样的图（两次输出 md5 一致）。

## 6. 注意事项

- 装帧三件套（`封面.png` / `封底.png` / `书脊.png`）一旦重出，**必须重跑本脚本**，否则效果图里的书和实际印刷品会不一致。
- 效果图里的书是「立着的」姿态，靠影子压住；这是电商渲染的常见处理，不代表实物的真实摆放方式。
- 画面里的书没有做真实装订的曲面（书脊是平的折面）。若要更接近实物，需要额外的曲面弯曲处理 —— 当前版本在电商缩略图尺度上看不出差别。
