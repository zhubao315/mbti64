## R2–R3｜横向溢出：一次修错，一次修对

- R2 方案：`.grid:not([class*="grid-cols-"])` —— **无效**，因为 `md:grid-cols-2` 也含 `grid-cols-`，被 `:not` 排除。
- R3 方案：`grid-auto-columns: minmax(0, 1fr)`。
  - 只影响**隐式列**，不动显式模板，所以 `grid-cols-2` 的两列布局不受影响；
  - 修复后 `scrollWidth === innerWidth`（390）。
- 同时发现并修复：
  - 付费墙是「一大片模糊墙」，CTA 被挤到屏幕外 → 改为 `max-h-400px` + 底部渐隐 + 卡内按钮；
  - 彩带 `z-index: 60` 盖住导航与弹窗 → 降到 15（低于 header 30、弹窗 50）；
  - 海报头像用 emoji 绘制，在无彩色字体环境变「豆腐块」→ 改为 Canvas 自绘扁平头像；
  - 海报底部域名写成不存在的 `64personalities-cn` → 改为真实地址；
  - 海报文案「超过 6.5% 的人」语义不清 → 改为「比 6.5% 的人更稀有 / 最常见的一档」。

## R4–R5｜交互细节与回归

- 结果页移动端新增常驻「分享 / 看榜单」底栏（分享是最高频动作）；

- R5 回归：0 高 / 0 中，仅剩「装饰性文本链接 < 40px」低优先项。

## R8｜无障碍审计暴露的系统性问题

axe-core 报告 **589 处** `color-contrast`（serious）：

| 场景 | 数量 | 原因 |
|------|------|------|
| 首页 | 100 | 次要文字 `#8B85A0` 对白底仅 3.5:1 |
| 榜单 | 418 | 同上 + 档位徽标用亮色做文字（金 `#C9A227` 仅 2.4:1） |
| 型别页 | 61 | 主题卡标题用亮色、匹配百分比用 `#7FD1AE`（1.79:1） |

另有 1 处 `aria-hidden-focus`：付费墙锁定区里包含可聚焦的链接。

## R9｜对比度修复（设计层，不是打补丁）

做法：**同色相分两层** —— `color` 用于插画/渐变/浅底，`text` 用于文字，保证 ≥ 4.5:1。

| Token | 旧值 | 新值 | 对比度 |
|-------|------|------|--------|
| `ink.mute` | `#8B85A0` | `#6E6785` | 3.5 → 5.4 |
| `coral.deep` | `#E05C5C` | `#B33F3F` | 3.6 → 5.6 |
| `avocado.deep` | `#3F9C7A` | `#2A6B52` | 3.3 → 7.0 |
| `GROUP_META.text` | 新增 | 分析师 `#5B3FCC` / 冒险家 `#C94545` / 外交家 `#2A6B52` / 守护者 `#2A6FA8` | ≥ 5.5 |
| `RarityTier.text` | 新增 | 7 档各自加深（金 `#7A5E0B`、橙 `#A9531F`…） | ≥ 4.6 |
| 教学卡 / 雷达图标签 / 匹配百分比 | 用亮色 | 改用 `text` 层 | ≥ 5 |

其它修复：

- 锁定区不再渲染带链接的主题卡（`aria-hidden-focus` 消失）；
- 结果页「比 X% 的人更稀有」在 0% 时改为「属于最常见的一档」。

R9 结果：首页 / 榜单 / 型别页 / 答题页 / 结果页 / 分享面板 / 付费墙 **axe 0 违规**。

## R10｜最终回归

- 线上全站巡检：0 高 / 0 中，仅 18 条「文本链接 < 40px」低优先提示（导航与 sr-only 跳转链接）
- 64 个型别页：0 断链、67 个唯一标题、64 张 OG 图
- 性能（线上，压缩后）：首页 ~200 KB / 16 请求，型别页 ~29 KB / 18 请求
- 新增「复制这一型的链接」，强化型别页的分享入口

## 遗留与后续（不阻断发布）

1. **统计接口**：静态导出不支持 API Route；迁到 Node 托管后启用 `POST /api/results` + `blendStats`
2. **真实支付**：付费墙当前只做本地解锁，接支付需要服务端校验
3. **emoji 依赖**：极少数无彩色字体环境的 Linux 会把装饰 emoji 显示为方框（不影响功能）
4. **档位人数**：受「同概率同档」约束，实际为 `[2,6,8,10,12,12,14]` 而非目标 `[3,6,7,10,12,14,12]`，已在文案中说明
5. **文本链接点击区**：导航与面包屑 34–36px，略低于 40px 的经验值（WCAG 2.5.8 要求 24px，已满足）
