# MBTI64 心理测量学设计文档

> 角色：psychometrics（心理测量学）× 大五/MBTI 交叉研究视角
> 目标：让 A/C（坚定 vs 审慎）与 O/H（求新 vs 守成）两个自研扩展维度具备学术严肃性与行为预测力

---

## 一、A/C 维度：15 道高区分度、防社情偏差的行为选择题

设计原则：全部为**具体情境下的行为反应**，而非特质自评（"我是一个自信的人"）。
反向计分题（reverse）用 `R` 标注。二选一题（B）强制 ipsative，避免中庸。

**防社情偏差设计要点**
- 避免"自信/不自信"等自我评价词，用具体行为（"手心出汗""反复点开"）。
- A/C 两端各有代价：A 的代价是"低估失误"，C 的代价是"自我审判"；题目呈现双方代价，避免一端明显更"好"。
- 反向题 3 道（AC-01/03/08），降低 acquiescence bias。
- 二选一题强制选择，避免中庸作答（ipsative）。

## 三、64 组合计分加权算法（伪代码）

```
INPUT:  answers[Q] ∈ {0..4 (Likert) | "A"/"B" (binary)}, Q ∈ {AC-01..15, OH-01..15}
OUTPUT: code ∈ {64 types}, displayCode (含 ? 占位), swing, tier

// 1. 基础四字母（已有 EI/SN/TF/JP，此处略）

// 2. 后缀维度计分（AC / OH 各一套）
function scoreSuffix(dim, items):
  // items: list of { id, type, pole (A/O=+1, C/H=-1), reverse, weight }
  likertSum = 0; likertN = 0; binA = 0; binB = 0; binTotal = 0
  for item in items:
    if item.type == "likert":
      raw = answers[item.id]  // 0..4
      val = item.reverse ? (4 - raw) : raw   // 0..4, 高=poleA
      likertSum += val * item.weight
      likertN += item.weight
    else: // binary
      choice = answers[item.id]  // "A" | "B"
      if choice == "A": binA += 1
      else: binB += 1
      binTotal += 1

  // Likert 侧：转为 0..100 百分比（poleA 侧）
  likertPct = likertN > 0 ? (likertSum / (likertN * 4)) * 100 : 50

  // Binary 侧：ipsative 投票
  binPct = binTotal > 0 ? (binA / binTotal) * 100 : 50

  // 混合：Likert 60% + Binary 40%（binary 强制选择，区分度更高）
  blended = 0.6 * likertPct + 0.4 * binPct

  // 极性：poleA (A/O) 若 blended >= 50
  pole = blended >= 50 ? "A/O" : "C/H"
  preferred = max(blended, 100 - blended)   // 50..100
  strength = preferred < 55 ? "fuzzy" : preferred < 70 ? "moderate" : "strong"

  // 摇摆判定：binary 票数未达 ceil(2/3)
  need = ceil((2/3) * binTotal)
  swing = (binTotal > 0) and (max(binA, binB) < need)

  // IRT 加权：高区分度题权重更大（a 参数），难度居中（b 参数）
  // weight(item) = 1 / (1 + exp(-1.7 * a * (theta - b))) 的导数近似
  // 此处简化为静态权重表，由预实验标定

  return { pole, preferred, strength, swing, binA, binB, binTotal, need, blended }

// 3. 组装 code
ac = scoreSuffix("AC", AC_ITEMS)
oh = scoreSuffix("OH", OH_ITEMS)
base = EI.pole + SN.pole + TF.pole + JP.pole   // 16 型
code = `${base}-${ac.pole}-${oh.pole}`            // 64 型合法编码
displayCode = `${base}-${ac.swing ? "?" : ac.pole}-${oh.swing ? "?" : oh.pole}`

// 4. 稀有度：先验概率 × 排名分桶（lib/rarity-core.js 单一事实源）
// 5. 摇摆型：displayCode 含 ?，code 仍为合法 64 型

// 6. 社情偏差校正（可选后处理）
// residualize scores on a social desirability scale (Crowne-Marlowe SDS)
// adjusted = raw - beta * SDS_score
```

**IRT 参数建议**
- 每题标定 discrimination `a ∈ [0.8, 2.0]` 与 difficulty `b ∈ [-2, 2]`
- 高 a 题（如 AC-10 二选一）权重 ×1.5
- 反向题与正向题 a 参数应相近，避免 acquiescence
- 二选一题（binary）天然 ipsative，区分度 > Likert

**区分度保障**
- 64 组合 × 每维 15 题 → 每维信息量 ≥ 4 bits（15 题 × 平均 0.3 bit）
- 摇摆型（?）作为"未决"状态，不强行归类，降低误判

## 四、巴纳姆效应（Barnum Effect）盲区与优化建议

### 4.1 已识别的盲区

1. **泛化描述**：如"你既独立又需要被理解"——所有 64 型都可套用，产生"说的就是我"的错觉。
2. **正向偏置**：所有型别描述以优势开头，用户倾向接受正面描述（Forer 1949）。
3. **稀有度光环**：标记"万里挑一"会提升接受度，与内容无关。
4. **自我选择偏差**：用户只记住符合的句子，忽略不符的（confirmation bias）。
5. **64 型 ≠ 64 种人格**：真实人格分布连续，64 离散格子是模型强加的边界，相邻格子描述可能高度重叠。
6. **后缀维度的 Barnum 风险**：A/C、O/H 的描述（"你不太需要别人反复确认你是对的"）同样泛化。

### 4.2 优化建议

1. **具体化、可证伪的预测**：每型描述包含 3 条"如果你是 X 型，你很可能在 Y 情境下做 Z"的具体预测，用户可自行验证。
2. **"不是你"声明**：每型描述末尾加"如果你发现自己完全不像以上描述，你可能是相邻型 Y"，引导用户校准。
3. **基础率锚定**：明确写出"该型在人群中的先验概率约 X%"，避免稀有度被误读为"独特性"。
4. **行为频率 anchors**：用"每周至少 X 次"而非"你经常"，减少模糊词。
5. **差异化测试**：每型描述必须通过"相邻型区分度测试"——与最相近型的描述差异 ≥ 3 个具体行为预测。
6. **负向描述纳入**：每个型别包含 1-2 条"你可能不擅长/容易踩的坑"的负面描述，平衡正向偏置。
7. **用户反馈校准**：结果页提供"这个描述准吗？"1-5 评分，收集数据持续修正。
8. **学术边界声明**：明确"64 型是探索框架，非心理测量学标准分类"，避免医疗/诊断用途。

### 4.3 验证指标

- **区分度**：两两型别描述的余弦相似度 < 0.7（文本层面）。
- **Barnum 指数**：对未测用户展示随机型别描述，接受度应 < 60%（Forer 期望 ~80%）。
- **重测信度**：同一用户 4 周后重测，code 一致率 ≥ 70%。
- **预测效度**：后缀维度与真实行为（如职业选择、消费记录）的相关 r ≥ 0.2。
