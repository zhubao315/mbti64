## 编制原则

1. **插图是帮助理解的示意，不是证据**。任何图都不得标注为「脑区分布」「神经亚型」「人群比例实测」；涉及稀有度的图必须带「模型计算，非人口统计」字样。
2. **不重新生图，不虚构已有资产**。六卷扉页、封面 / 封底 / 书脊、16 基础原型与圆桌场景均复用 `refs/` 中已通过 QC 的参考图；卷名、书名与边界说明由 `resvg` 在排版层叠加，符合视觉圣经「文字不入图」的分工。图 7、8、9、12 为矢量信息图，其中图 8 的数值全部由 `lib/rarity-core.js` → `docs/64型稀有度权威数据.json` 生成。
3. **两套输出**：`书-千分之一的你/插图/` 为含叠加文字的排版终稿（供纸书与 EPUB）；`public/assets/book-visual/volumes/volume-0N-blank.png` 为无文字底图，供网站自由排版。
4. 图注统一采用「图 X · 图题」格式，图下附边界说明；合订本以 `![...](插图/图NN.png)` 引用真实图片，EPUB 打包时改写为 `images/plate-NN.png`。

## 图注排版规范

- **图题格式**：`图 X · 图题`，置于图下；图注另起一行，字号小于正文。
- **边界说明**：图 1、7、8、9、12 必须带「模型示意 / 非人口统计 / 非发展定律 / 非截止日」中的对应字样；图 10、11 必须带「创作素材，非调研记录」。以上文字已直接排入终稿图。
- **禁止项**：不得出现「脑区激活」「神经亚型」「EEG 分型」「真实人口占比」「已被科学证明」等表述；不得把档位名画成社会阶层金字塔。
- **数据图**（图 8）：数值必须由 `lib/rarity-core.js` → `docs/64型稀有度权威数据.json` 生成，禁止手填；图内并列名次写区间（如 `1–2`、`51–64`），不写「第 N/64」。
- **版权与一致性**：人物发色、服装色板、7 头身比例沿用 `docs/book-visual/01-视觉圣经.md`；所有插图与网站型别卡保持同一视觉体系。
- **字形**：书名大字用 `SimHei`（雅黑粗体会把「千」的上撇压成近水平，易被误读为「干」）；其余文字用 `Microsoft YaHei`。
