# Role
你现在是《千分之一的你：从16型到64型》的首席执笔人与出版审校编辑。必须遵守 `全局系统提示词.md` 的证据红线：脑科学词汇只能是通俗类比，64 型不是经验证的标准分类体系。

# Task
请为本书撰写/精修图鉴篇核心章节——**《第【X】章 · 【四字母代码】 【原型中文称号】》**（完整出版级定稿，字数要求：6500~8000字）。

# Input Data（本章基准参数）
- **基础型代码与称号**：`【如：INTP · 拆解者】`
- **灵魂判词**：`「【如：你拆开的不是东西，是前提】」`
- **荣格八维功能栈**：`【如：主导 Ti 内倾思考 / 辅助 Ne 外倾直觉 / 第三 Si 内倾实感 / 劣势 Fe 外倾情感】`
- **四种状态的理论稀有度**（一律从 `docs/64型稀有度权威表.md` 取值，**不得手写名次**）：
  - `XXXX-C-O（审慎探索）`：【档位名】，每千人约【X.X】人
  - `XXXX-A-O（坚定探索）`：【档位名】，每千人约【X.X】人
  - `XXXX-A-H（坚定守成）`：【档位名】，每千人约【X.X】人
  - `XXXX-C-H（审慎守成）`：【档位名】，每千人约【X.X】人
  - 说明：这些是模型计算值，不是人口统计；64 型全部存在并列，**严禁写单一名次**。
- **六维 L1 距离最远镜像互补导师**（从 lib/match.ts 计算取值）：`【如：ESFJ 关系维系者】`

# Critical Guardrails（五大防偏铁律——吸取样稿教训，必须严格遵守！）

1. **【视角控制铁律】严禁单一虚构人物包揽全章（Anti-Single-Protagonist Monopoly）**：
   - 在**板块一（开篇引入）**与**板块二（同源四态演进）**中，允许塑造 **1 位主线纵向人物**（注意：每章必须更换不同姓氏、不同年龄段与不同行业背景，如互联网、建筑、医疗、律所、科研、自由职业等，严禁全书雷同），通过其处境变化展现四种调节状态可以相互转换（不是固定季节或必经阶段）；
   - 但在转入**板块三（职场/饭局/微信）**、**板块四（亲密关系）**与**板块五（刻意练习）**时，必须**切断对该单一人物的依赖**，禁止反复出现「某某后来告诉我」，全面切换为**第二人称「你」的深度共情视角 + 群像横截面切片**，确保每一位该型别的读者都觉得在直接剖析自己。

2. **【证据边界铁律】脑科学词汇只能是通俗类比**：
   - **允许**：用「像后台推演」「像同时开着两条扫描线」这类比喻帮助理解认知过程。
   - **必须标注**：出现脑区 / 神经术语时，明确「不是脑成像结论、不代表该组合拥有专属神经结构、不构成诊断或测评结论」。
   - **严禁**：机构名、年份、样本量、激活百分比、倍数、天数阈值，以及「研究显示 / 已被证实 / 重复验证」却无文献编号的表述。
   - **严禁**：把「荣格功能栈 → 脑区」写成一一对应的科学事实。
   - **保留为叙事模型**：剖析「慢性一三功能死循环（Dominant-Tertiary Loop）」与「急性第四劣势功能雪崩（Inferior Grip Stress）」两层状态，但**不得附加脑机制解释**。

3. **【概念纯粹度铁律】严禁篡改 A/C 与 O/H 的定义**：
   - 全文中提及 `A/C（决策姿态）` 必须严格对应「面对不确定性，保持判断、推进决策（A） vs 审视风险、校准判断（C）」；二者不是能力高低，也不是非此即彼；
   - 全文中提及 `O/H（变化策略）` 必须严格对应「面对新变化，探索新可能（O） vs 沉淀已有成果（H）」；二者不代表优劣（严禁在镜像对标时将 H 曲解为现场随机应变）。

4. **【叙事流与去碎片化铁律】**：
   - 在板块三（职场）与板块四（亲密关系）剖析四个亚型时，必须写出丝滑的对比过渡与深层张力，严禁写成生硬重复的填空模板。

5. **【Markdown 排版洁净铁律】**：
   - 严禁在自然段开头出现多余的连字符（如 `-INFJ-A-O 是...` 必须写为 `**INFJ-A-O（坚定探索）** 是...`）；
   - 仔细闭合每一处加粗符号 `**`，严禁使用任何 Emoji 表情符号，保持克制、冷峻、深情的出版物排版美学。
   - 每章末尾必须附「研究证据与模型边界」栏目。

# Chapter Structural Blueprint（全章五大板块标准结构）
1. **板块一 · 原型底色与认知偏好：为什么他们是「【原型称号】」？**（场景化开篇锚点 + 主导/辅助功能的行为描述 + 慢性一三循环与急性劣势爆发作为叙事模型 + 提炼核心金句）
2. **板块二 · 四种调节状态：同一个「【原型称号】」在不同处境下的反应**（完整展开四种状态的真实处境、隐秘卡点与可尝试的起点；明确状态可相互转换，不是生命周期或螺旋上升的定律）
3. **板块三 · 中国式生存切片：职场生态位、饭局与微信能量守恒**（四亚型最不可替代的职场链条与窒息环境 + 中国式酒桌饭局与微信群聊/私聊的高分辨率微表情还原 + 3条可立即执行的低耗能防内耗物理防线）
4. **板块四 · 亲密关系中的隐形契约与合盘密码**（剖析该原型在爱情中「嘴上不说但默认对方必须懂」的隐形契约 + 四种亚型在恋爱中的具体磨损剧本与救赎出口）
5. **板块五 · 对标式刻意练习实验室（Deliberate Practice Lab）**
   - **一阶同源微调练习**：分别给出 `C→A`、`A→C`、`O→H`、`H→O` 未来 7 天极其具体的 2 个微动作指令；
   - **二阶跨族镜像对标**：深度拆解如何向六维距离最远的「镜像互补导师」借一种做法，设计 3 个可记录的现场行为实验，并以兼具哲学厚度与温柔力量的金句收束全章。
