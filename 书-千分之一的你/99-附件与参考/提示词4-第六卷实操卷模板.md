# Core Content Requirements

## 第一部分：构建「人生六大卡点 × 64型对标处方笺」
请针对当代人最常见的6种人生阶段性困局，给出精准的「对标型别（Benchmark Type）」与神经回路激活方案：

### 困局 1：想得太多、迟迟不敢启动（高 C + 高 N/P 瘫痪）
- **对标靶心**：`ESTP-A-O（局面拆弹手·坚定探索）` 与 `ENTJ-A-O（推土机型统帅·坚定探索）`
- **神经回路原理**：Se 外倾实感的即时行动驱动 + Te 外倾思考的成本收益快速计算
- **微行为方案**：具体到办公桌前可执行的3个每日微动作

### 困局 2：三分钟热度、到处开荒却攒不下复利（高 O + 高 P 耗散）
- **对标靶心**：`ISTJ-A-H（地基工程师·坚定守成）` 与 `INTJ-A-H（冷焰策士·坚定守成）`
- **神经回路原理**：Si 内倾实感的结构化封存 + Ni 内倾直觉的长期主义复利
- **微行为方案**：具体的「每日15分钟复利沉淀仪式」设计

### 困局 3：在人际关系中过度讨好、背负他人情绪黑洞（高 F + 高 C 内耗）
- **对标靶心**：`ISTP-A-H（手上见真章·坚定守成）` 与 `INTP-A-O（拆解者·坚定探索）`

- **微行为方案**：「情绪防火墙1.0」七阶段训练

### 困局 4：体制或成熟赛道温水煮青蛙、丧失破局勇气（高 H + 高 S/J 僵化）

- **微行为方案**：「5分钟副业探针」设计

### 困局 5：强势推进导致众叛亲离、听不见伴侣与下属的沉默（高 A + 高 T 盲区）
- **对标靶心**：`INFJ-C-H（深夜点灯人·内省守成）` 与 `ISFJ-C-H（沉默后勤部·内省守成）`
- **神经回路原理**：Fe/Fi 的留白倾听 + 非语言信号捕捉训练
- **微行为方案**：「沉默观察日记」训练

### 困局 6：长期高压后的灵魂干涸与意义感丧失（全维度过载）
- **对标靶心**：`ISFP-C-H（感官诗人·内省守成）` 与 `INFP-C-H（内心博物馆·内省守成）`

- **微行为方案**：「每日5分钟感官锚点」练习

## 第二部分：设计「30天六维可塑性训练矩阵（30-Day Neuro-Sculpting Protocol）」
将30天分为四个周期，每一阶段必须提供极度具体、可在办公桌前、通勤路上、微信聊天或家庭晚餐时直接执行的「微动作指令（Micro-Actions）」与「自我校准提问」：

### 第一周：觉察惯性（绘制你的六维能量漏斗）
- 每日微动作：六维能量日志（记录每小时的维度表现）
- 自我校准提问：今日我在哪个维度上能量漏斗漏得最厉害？

### 第二周：同源后缀切换（A↔C 与 O↔H 的阻尼调节）
- 低 A 者 → A 脱敏训练（拍板练习）
- 低 C 者 → C 共情校准（留白倾听练习）
- 低 O 者 → O 微越界（低成本试错）
- 低 H 者 → H 复利沉淀（每日固定仪式）

### 第三周：镜像导师附体（每日1小时跨型别角色扮演）
- 每天挑选一个互补镜像型别
- 1小时内「穿上对方的人格盔甲」去处理一件小事
- 事后复盘：哪些部分让我舒服？哪些部分让我不适？

### 第四周：动态圆融整合（建立个人多模态应对切换开关）
- 为每种场景（职场、家庭、社交）设计自己的「最佳型别状态」
- 建立可随时调用的工具箱
- 最终产出：一份属于自己的「64型工具箱使用手册」
